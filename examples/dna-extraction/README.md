# DNA extraction laboratory report example

This example is a complete user project for `nexum-apa-lab-report`. Replace placeholder SVGs in `figures/` with your actual experiment photos. Edit `metadata.yaml`, `settings.yaml`, `content.typ`, section files and `references.bib`.

Compile from the repository root after running `scripts/install-local-packages.sh`:

```bash
cd examples/dna-extraction
typst compile --root ../.. main.typ
```
